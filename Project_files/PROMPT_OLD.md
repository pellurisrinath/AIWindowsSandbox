# 🤖 GPT Prompt — Windows AI Sandbox

> Use this prompt with Claude, GPT-4o, or Gemini to generate or regenerate the PowerShell scripts for this project. Feed it as a single user message. The model will produce all three scripts and a usage guide in sequence.

---

## Prompt

```
You are an expert Windows PowerShell engineer and Windows Sandbox automation specialist.

## Project
"Windows AI Sandbox" — a fully automated, disposable Windows Sandbox environment
provisioned via PowerShell. A single host-side script downloads all required installers,
generates the sandbox configuration, launches the sandbox, and runs a bootstrap script
at logon to silently install all tools. When the sandbox closes, nothing persists.

## Deliverables
Produce in this order:
1. Launch-AISandbox.ps1         — host-side launcher script
2. sandbox-config.wsb           — Windows Sandbox XML configuration (auto-generated by launcher)
3. scripts/sandbox-bootstrap.ps1 — logon script that runs inside the sandbox
4. config/tools.json            — central tool registry
5. Usage guide with example commands

## PART 1 — Host-Side Launcher: Launch-AISandbox.ps1

### Behaviour
- Must run as Administrator; self-elevate if not already elevated
- Check that Windows Sandbox feature is enabled:
    Get-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM
  If not enabled, prompt user to enable it via:
    Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All
  Then exit — user must reboot before continuing.
- Create a temp shared folder at $env:TEMP\AISandboxShare\
- Download all required installers sequentially to $env:TEMP\AISandboxShare\Installers\
  using Invoke-WebRequest with -UseBasicParsing and progress display
- Clone the Page Assist Chrome extension from:
    https://github.com/n4ze3m/page-assist
  into $env:TEMP\AISandboxShare\Extensions\page-assist\
- Generate sandbox-config.wsb dynamically (see PART 2)
- Launch the sandbox: Start-Process WindowsSandbox -ArgumentList $wsbPath
- Wait for sandbox to close
- Optionally clean up shared folder if -CleanCache is set

### Skip Flags (each is a [switch] parameter)
-SkipOllama, -SkipLMStudio, -SkipOpenCode, -SkipCrewAI,
-SkipChrome, -SkipPageAssist, -SkipBrave,
-SkipNotepadPP, -SkipBeyondCompare, -SkipNpm, -SkipPython, -SkipGit,
-SkipVSCode, -SkipVSCommunity,
-SkipPowerToys, -SkipSysinternals, -SkipADK, -SkipSDK, -Skip7Zip,
-SkipCopilot

### Other Parameters
-SandboxMemoryMB [int]     default 16384   RAM to allocate to sandbox
-PreCacheOnly  [switch]                    Download installers but do not launch sandbox
-CleanCache    [switch]                    Delete shared folder after sandbox closes
-Verbose       [switch]                    Detailed console progress

### Download URL Strategy (CRITICAL)
Do NOT hardcode version numbers. Resolve the latest version dynamically:
- GitHub releases:  use the GitHub API:
    https://api.github.com/repos/OWNER/REPO/releases/latest
  Then extract browser_download_url for the appropriate asset.
- Official vendor CDNs that always resolve to latest (use these directly):
    Chrome:       https://dl.google.com/chrome/install/ChromeStandaloneSetup64.exe
    Brave:        https://laptop-updates.brave.com/latest/winx64
    Ollama:       https://ollama.com/download/OllamaSetup.exe
    Node.js LTS:  https://nodejs.org/dist/latest-v20.x/  (parse for .msi)
    Notepad++:    resolve from GitHub API - notepad-plus-plus/notepad-plus-plus
    VS Code:      https://code.visualstudio.com/sha/download?build=stable&os=win32-x64-user
    PowerToys:    resolve from GitHub API - microsoft/PowerToys
    Git:          resolve from GitHub API - git-for-windows/git
    7-Zip:        https://www.7-zip.org/download.html (parse page for latest .exe)
    Beyond Compare: https://www.scootersoftware.com/download (parse for latest)
    Sysinternals: https://download.sysinternals.com/files/SysinternalsSuite.zip
    ADK:          https://go.microsoft.com/fwlink/?linkid=2289980
    ADK WinPE:   https://go.microsoft.com/fwlink/?linkid=2289981
    Windows SDK:  https://go.microsoft.com/fwlink/p/?linkid=2237387
    LM Studio:    https://releases.lmstudio.ai/windows/latest
    Python:       https://www.python.org/ftp/python/ (parse for latest 3.x .exe)

### Skip Flag Propagation
Write the set of enabled/disabled tools to a config JSON file at:
  $env:TEMP\AISandboxShare\install-config.json
The bootstrap script reads this file to know what to install.

## PART 2 — Sandbox Configuration: sandbox-config.wsb

Generate this XML dynamically from the launcher script. Use these settings:

```xml
<Configuration>
  <vGPU>Enable</vGPU>
  <Networking>Enable</Networking>
  <MemoryInMB>16384</MemoryInMB>
  <MappedFolders>
    <MappedFolder>
      <HostFolder>C:\Users\...\AppData\Local\Temp\AISandboxShare</HostFolder>
      <SandboxFolder>C:\SharedTools</SandboxFolder>
      <ReadOnly>true</ReadOnly>
    </MappedFolder>
  </MappedFolders>
  <LogonCommand>
    <Command>powershell.exe -ExecutionPolicy Bypass -File C:\SharedTools\sandbox-bootstrap.ps1</Command>
  </LogonCommand>
</Configuration>
```

Replace HostFolder with the actual resolved path. Replace MemoryInMB with the value
of -SandboxMemoryMB.

## PART 3 — Bootstrap Script: sandbox-bootstrap.ps1

This script runs inside the sandbox at logon. It must:

### Startup
- Set $ErrorActionPreference = "Continue" so failures don't abort the whole script
- Source shared utilities from C:\SharedTools\utils.ps1
- Read install-config.json from C:\SharedTools\ to determine what to install
- Create a log file at C:\sandbox-install.log
- Define a helper function Write-Log that timestamps every line

### Install Order (strict — dependencies first)
1.  **7-Zip**          — required for extracting some installers
2.  **Git**            — required for cloning Page Assist extension
3.  **Python 3**       — required for crewai (pip)
4.  **Node.js + npm**  — required for some AI tools
5.  **Google Chrome**  — required before Page Assist and Copilot PWA
6.  **Page Assist**    — Chrome must already be installed; run Chrome with
                          --load-extension=C:\SharedTools\Extensions\page-assist
                          Create a desktop shortcut with this flag pre-applied.
7.  **Brave Browser**
8.  **Notepad++**
9.  **Beyond Compare 4**
10. **Visual Studio Code**
11. **Visual Studio Community**  — use vs_buildtools.exe or vs_community.exe with
                                    --quiet --wait --norestart flags
                                    Default workloads: Microsoft.VisualStudio.Workload.ManagedDesktop,
                                    Microsoft.VisualStudio.Workload.NativeDesktop,
                                    Microsoft.VisualStudio.Workload.Node
12. **Windows PowerToys**
13. **Sysinternals Suite**       — extract zip to C:\Tools\Sysinternals, add to PATH
14. **Windows ADK**
15. **Windows ADK WinPE Addon**
16. **Windows SDK**
17. **Ollama**                   — install, then start the ollama service
18. **nous-hermes2 model**       — ollama pull nous-hermes2 (runs after Ollama starts)
19. **LM Studio**
20. **OpenCode**                 — download latest GitHub release binary
21. **Crew AI**                  — pip install crewai
22. **Microsoft Copilot PWA**    — launch Chrome with:
                                    --app=https://copilot.microsoft.com
                                    (user must sign in manually)

### For each tool install block, follow this exact pattern:
```powershell
if ($config.tools.toolName.enabled) {
    Write-Log "Installing ToolName..."
    try {
        $installer = "C:\SharedTools\Installers\toolname-installer.exe"
        $proc = Start-Process -FilePath $installer -ArgumentList "/S" -Wait -PassThru
        if ($proc.ExitCode -eq 0) {
            Write-Log "[OK] ToolName installed successfully"
        } else {
            Write-Log "[WARN] ToolName installer exited with code $($proc.ExitCode)"
        }
    } catch {
        Write-Log "[ERROR] ToolName install failed: $_"
    }
} else {
    Write-Log "[SKIP] ToolName (disabled by config)"
}
```

### Placeholder Tools (handle gracefully)
- **Antigravity 2.0 / IDE / CLI**: Attempt to resolve https://antigravity.google/download.
  If unreachable (timeout 10s), Write-Log "[SKIP] Antigravity — source unverified or unreachable"
  and continue. Do not hard-fail.
- **Hermes Agent**: No known installable binary. Log the substitution:
  Write-Log "[INFO] Hermes Agent: no CLI binary available; using nous-hermes2 via Ollama"

### Completion
- Write a summary section to C:\sandbox-install.log:
  - List every tool: [OK], [SKIP], [WARN], or [ERROR]
  - Total time elapsed
  - Any tools that need manual post-install steps (licence keys, sign-in, etc.)
- Show a Windows Toast notification:
    [System.Windows.Forms.MessageBox]::Show("AI Sandbox ready. See C:\sandbox-install.log")
  OR use BurntToast if available; fall back to MessageBox
